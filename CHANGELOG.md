# Changelog

## 0.1.0-alpha.1 — 2026-10-08

Initial experimental GitHub release for T3 Code and Codex.

- Learn/Reset skills preserving the original learner-led workflow.
- Read-only SessionStart restoration, legacy state, and T3 Plan/Default rules.
- Preview-first installation, preserved hooks, backups, and idempotence.
- Confirmed reset snapshots and repository/worktree/symlink protections.
- MIT notices, author attribution, English/Spanish docs, CI, and privacy checks.

### Known limitations

Full T3 conversations, actual lifecycle restoration, and educational quality need
end-to-end testing. Hooks need review/trust. Marketplace installation and
macOS/Windows/WSL are unverified. Automatic upgrades/uninstall are not implemented.
This alpha is published on GitHub, not OpenAI's public plugin directory.
